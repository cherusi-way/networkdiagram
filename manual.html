指先だけで、現場のネットワーク図を。

Network Diagram Builder は、スマホ・タブレットのタップ操作を前提に設計されたネットワーク構成図エディタです。機器の台帳・IP管理・検証までこの1画面で完結し、データはすべてお使いの端末の中に保存されます。

🧭やりたいことから探す

目的の言葉から、該当する章へジャンプできます。用語が分からないときは下の用語集へ。

機器を置く・動かす・つなぐ 線の速度・VLAN・見た目を変える 機器にIP・台帳情報を入れる IPの空き・重複・不備を調べる 同じ構成をまとめて量産する 現行/更改後を1枚で出し分ける 図を共有・印刷・他端末へ移す 枠・メモ・バスで見せ方を整える 拠点・案件をシート/プロジェクトで分ける アプリとして入れる・オフライン 隠れ操作(長押し・2回タップ)を一覧 用語を確認する

🚀はじめての1枚 — 5分クイックスタート

まずは「ルーター → スイッチ → PC」の3台をつないでみましょう。これだけで操作の8割が身につきます。

  1. 画面下のパレットから「ルーター」を選び、キャンバスの空白をタップして配置します。続けて「L2スイッチ」「PC」も置きます。
  2. ルーターをフリック(触れてすぐ動かす)し、指をスイッチの上まで運んで離すと接続線が引かれます。同様にスイッチ → PC もつなぎます。
  3. 機器をタップすると編集シートが開きます。名前・IPアドレス・拠点などを入力してみましょう(すべて任意項目です)。
  4. 空白をすばやく2回タップすると図全体が画面に収まります(右下の全体でも同じ)。
  5. ☰メニュー →「画像・印刷で共有」からPNG保存や印刷/PDFで書き出せます。作図内容は常時自動保存されているので、保存操作を意識する必要はありません。
操作に迷ったら、アプリ内の ☰メニュー → 操作ガイド(チートシート)でいつでも要点を確認できます。「ボタンが見当たらない」「この操作どうやるの?」と思ったら気づきにくい操作の早見表へ。

📲インストールと更新

ブラウザで開くだけでも使えますが、ホーム画面に追加すると全画面のアプリとして起動でき、オフラインでも動作します。

ホーム画面への追加

iPhone / iPad
Safariでこのサイトを開き、共有ボタン(□↑)→ ホーム画面に追加
Android
Chromeで開き、右上「︙」→ ホーム画面に追加。またはアプリ内 ☰メニュー →「アプリとして使う」のインストールボタン
PC
Chrome / Edge のアドレスバー右端に表示されるインストールアイコンをクリック

オフライン動作と更新

オフライン
一度開けば内容が端末にキャッシュされ、電波のない現場でも起動・編集できます。作図データも端末内保存なので通信は不要です。
更新
新しい版が公開されると、起動のたびに裏で自動取得され次の起動から反映されます。すぐ反映したい場合は ☰メニュー →「アプリとして使う」→ 🔄 最新版を再取得して再読み込み。更新しても作図データは消えません。
HTTPSで配信されている初回アクセス時は、画面上部にインストールのご案内が自動で表示されます(対応ブラウザのみ)。見送っても、いつでも上の手順で追加できます。
データはブラウザ内(localStorage / IndexedDB)に保存されます。ブラウザの「サイトデータ削除」やプライベートモードではデータが消えるため、大事な図は ☰メニュー →「データの保存・取込」→「JSONを保存」で定期的にバックアップしてください。

👆基本操作 — 3つのジェスチャー

機器への操作は「触れてからの動き」で分かれます。この3つを覚えればキャンバスは自由自在です。

タップ
→ 編集シートを開く
👆

触れて、動かさずに離す。名前・IP・ポート台帳などの編集シートが開きます。

フリック(すぐ動かす)
→ 接続線を引く
👆

触れてすぐ動かし、相手の機器の上で離すと配線。空白で離せばキャンセルです。

長押し → 動かす
→ 機器を移動
0.2秒
👆

少し押さえてから動かすと移動。掴めた瞬間に端末が振動してお知らせします。

「すぐ」と「少し」の境目(長押し判定時間)は 表示 → 操作の調整で 20〜400ms の間で好みに変えられます。フリック配線そのものをOFFにすることも可能です。

そのほかの基本

連続配置
パレットの部品をすばやく2回タップ(またはバナーの連続ON)で、同じ部品をタップするたびに配置できます。
配置時に名前入力
表示 → 配置時に名前入力をONにすると、置いた直後にその場で機器名を付けられます。
全体表示
空白をすばやく2回タップ、または右下全体。
取り消し
トップバーの ↶↷。履歴はシート単位で記録され、Undo時に「移動」「接続」など操作名がトーストで表示されます。シート削除やCSV取込の取り消しは、直後のトーストの元に戻すから。
枠(グループ)
枠は枠線かラベルをタップして選択。内側は素通りなので、枠の中の機器も普段どおり操作できます。
削除
機器・線・メモ・枠は、選択すると出るミニバーの🗑削除で消せます(PCは選択してDelete)。まとめて消すときは右下複数で選択 → 一括削除。誤って消しても直後のトーストの元に戻す、または↶で戻せます。

🖥機器

機器をタップすると編集シートが開きます。すべての項目は任意入力 — 図を描くだけでも、台帳として作り込んでも使えます。

持てる情報
ラベル(表示名)・サブラベル(2行目)・ホスト名・IPアドレス・サブネットマスク・デフォルトGW・拠点・ベンダー・型番・シリアル番号・資産管理番号・保守期限・備考・ポート台帳。
素早い作図ではIP欄が空でも、サブラベルにIP表記(例 192.168.1.20)を書けば、それを機器のIPとして検証・IP集計に拾います。
見た目の変更
編集シートの見た目で役割を表現で、アイコン差し替え・スタイル3種(線画/塗り/タイル)・形(四角/ピル/六角形)・枠線の太さ・文字サイズ・機器サイズ(85〜150%)を変更。コア機器を特大+塗り+太枠で目立たせるといった表現ができます(種類や台帳の意味は変わりません)。さらに枠の色で役割・系統を手動で色分けできます(IPごとに自動で塗る「セグメント色分け」とは別のものです)。
二重化バッジ
機器の編集で冗長構成(STACK / HA / CLUSTER / DR)を選ぶと、機器の角にバッジが付き、HAやスタックは2台重なった見た目になります。サブラベルに Act/Stby などを添えれば冗長構成が一目瞭然です。
複製(連番)
機器を選択 → ミニバーの複製で、ラベル末尾の数字とIPの第4オクテットが未使用の次の番号に自動更新されます(AP-01→AP-02、.11→.12)。同種の機器を並べる作業が一気に速くなります。
ポート台帳
「ポート台帳」に1行1ポートで定義すると、接続時にプルダウン選択でき、二重使用も警告されます。Gi0/0 203.0.113.1/30 # 対ISP のようにポート単位のIP・VLAN・備考も持てるため、ルーターの複数IP管理にも対応します。
位置の固定
編集シートの位置を固定で誤ドラッグを防止(🔒表示)。
同名機器(全体図+詳細図)
同じ機器(ホスト名またはラベルが同一)を複数のシートに描けます。編集シートに「他◯箇所にも掲載」と相違の有無が表示され、編集後は他シートへの反映やまとめて改名をトーストで提案。内容が食い違ったときは「図の検証」で一覧し、その場で揃えられます。
リンク先シート
機器の編集でリンク先シートを設定すると、その機器のタップで別シートへジャンプできます。全体図の「東京拠点」から拠点詳細図へ飛ぶ、といったドリルダウン構成に。ジャンプ後は画面上部に← 元のシート名の戻るボタンが出ます。リンク先がある機器は、選択時のミニバー↗ 詳細へからも飛べます。
編集シートの記憶
編集シートで開いた詳細情報・ポート台帳・見た目・ケーブル情報などの開閉状態は記憶され、次に開くときも同じ状態で表示されます(端末内に保存)。よく使う欄だけ開いておけます。

🔗接続(配線)

機器どうしをつなぐ線の引き方と、速度・VLAN・経路などの編集です。

線を引く
機器をフリックして相手の上で離す。周囲の⊕ドラッグや、選択 → 接続 → 相手をタップでも引けます。接続中バナーの連続をONにすると同じ起点から次々つなげます。
持てる情報
両端のポート名・両端ラベル・VLAN(アクセス/トランク、10,20,30-39形式)・線種・回線速度(100M〜100G、太さに反映)・色・矢印・変更ステータス・ケーブル種別(Cat6A/OS2/DACなど)・備考(キャリア名・回線番号・契約帯域・障害時連絡先などWAN回線情報の置き場に)。
線パレット
線を選択すると左上に線スタイルパレットが出現。経路(直線/直角)・線種・回線速度を、編集シートを開かずワンタップで切り替えられます。
既定スタイル
表示 → 線の既定スタイルで「これから引く線」の書式をプリセットまたは個別指定。気に入った線ができたら、その線の編集のこの線のスタイルを既定にするで取り込めます。
付け替え・反転
線を選択 → 両端の●をドラッグで別の機器へ付け替え。逆向きに引いてしまった線は⇄ 両端の設定を入れ替えでラベル・接続位置・矢印をワンタップ交換。
経由点(迂回)
線を選択 → 線上の「+」をドラッグで経由点を追加し、機器を避けて配線を曲げられます(1本あたり8個まで)。隣の点に重ねると削除。
ポート即時選択
ポート台帳を持つ機器を接続した直後、画面下のチップ列から両端のポートをその場で選択できます(使用中ポートは薄表示)。
折れ・ラベル
直角線は○で折れ位置を調整。中央ラベルはドラッグで移動できます。

📝メモ・枠・バス(作図部品)

パレットの「作図」カテゴリには、機器以外の表現部品が入っています。

グループ枠
拠点・ラック・セキュリティゾーンなどの「まとまり」を四角で囲みます。枠を動かすと中の機器も一緒に動くので、拠点単位のレイアウト調整に便利。選択は枠線かラベルをタップ(内側は素通り)。色とラベルを変更できます。
メモ
付箋スタイルの注記。サイズ・色を選べ、障害対応メモや作業予定の書き込みに。
テキスト
背景が透明な文字だけの注釈。図のタイトルや補足説明を、図の見た目を邪魔せずに置けます。
バス(セグメントバー)
横長のバーで1つのネットワークセグメントを表現します。バーに機器を接続すると縦線でぶら下がる、教科書でおなじみのバス型の描き方。バーは横にリサイズでき、セグメント名やネットワークアドレスをラベルに。多数の機器が同居するセグメントを、線を張り巡らせずスッキリ描けます。

⛶複数選択と一括編集

複数の要素をまとめて選び、整列・一括編集・コピー・テンプレ化ができます。

選ぶ
右下の複数ボタン → 機器・線・メモ・枠をタップで追加、または空白をなぞって範囲選択。なぞり選択では選択した機器につながる線も自動で選ばれます。
できること
一括編集(種類・拠点・マスク/GW・ステータス・色・回線速度・線種・VLANなど)・整列・等間隔・コピー&貼り付け(別シートへも可)・テンプレート登録・一括削除。
一括置換
一括編集内の一括置換で、コピーした拠点のIP(10.1.→10.2.)と名称(A-→B-)をまとめて付け替え。拠点の横展開が数タップで終わります。
テンプレ登録
選択した一式をパレットに登録して何度でも再利用できます。手順は次章「テンプレート」で詳しく。

📦テンプレート — よく使う構成の再利用

「標準拠点セット」「島ハブ+PC6台」のような自分がよくコピペする一式を部品化して、パレットから何度でも配置できます。大量展開の最強の時短機能です。

登録する

  1. 右下の複数ボタンをONにして、登録したい機器をなぞって範囲選択(またはタップで追加)。選択した機器どうしの接続線・メモ・枠も一緒に登録されます。
  2. 選択中に表示されるバーのテンプレ登録をタップ。バーに見当たらないときは、バー右端の「›」の先に隠れています(横にスクロール)。
  3. 名前を付けて(例: 標準拠点セット)登録完了。
線「だけ」は登録できません。両端の機器も含めて選択してください。

配置する

  1. パレットのカテゴリチップからテンプレートを選びます。
  2. 登録した一式が部品として並ぶので、通常の機器と同じく選んで空白をタップ。何度でも、別のシートにも配置できます。

管理する(共有・削除)

共有 / 削除
パレットのテンプレートを長押しすると管理メニューが開きます。全プロジェクトで共有でどのプロジェクトからも使える共有テンプレート(🌐)に、削除で取り除けます(登録数に上限はありません)。
中身の更新
テンプレート自体の編集はできません。配置 → 修正 → 再登録して古い方を削除、が更新の手順です。
配置後に一括編集 → 一括置換(10.1.→10.2. / A-→B-)を組み合わせると、テンプレートから複製した拠点のIPと機器名が数タップで付け替わります。拠点の量産はこのコンボが最速です。

👁表示と作図設定(右下「表示」)

見え方と作図の好みは、右下の「表示」ボタンに集約されています。

セグメント色分け
同一IPセグメントの機器を同色の背景で表示。サブネット構成がひと目で分かります。
IPアドレス強調
IPをチップ表示で強調(出力画像にも反映)。
交差をまたぐ
線の交差点を半円で跨いで描画し、T分岐との誤読を防ぎます(シート単位・出力にも反映)。
変更ステータス
全表示 → 更改後(廃止を隠す)→ 現行(新設を隠す)を巡回。1枚の図で現行/更改後を切り替えて見せられます。
用紙ガイド
A4/A3(横・縦)の比率枠を表示し、印刷時の収まりを見ながらレイアウトできます(出力には写りません)。
下絵(フロア図)
写真や図面画像をシート背景に敷いて、その上をなぞって作図(トレース)。濃さ・位置・大きさを調整でき、表示中は出力にも写ります(非表示にすれば図だけを出力)。
レイヤー
物理配線/論理フローなどを層に分けて表示切替。👁で表示、名前タップで作図先、⋯で名前変更・ソロ表示・削除。出力は表示中のレイヤーのみです。
ダーク / ミニマップ
キャンバスを暗く(出力は白のまま)。ミニマップはタップでジャンプ。
操作の調整
長押し判定時間(20〜400ms)・フリック配線のON/OFF・ブラウザのピンチ拡大許可など、操作感のカスタマイズはここ。
配置・接続の補助
配置時に名前入力=置いた直後に機器名を入力。接続時にポート選択=線を引いた直後にポートチップでポートを指定。作図のテンポに合わせてON/OFFできます。
描画互換モード
一部の古い環境で図が乱れる場合の保険的な設定。通常はOFFのままで構いません(見え方が安定しないときだけON)。

🗂シートとプロジェクト

「シート」は1枚の図、「プロジェクト」はシートの束(会社・案件単位)です。

シート
タブをタップで切替、表示中のタブをもう一度タップで設定(名前・複製・移動・削除)。タブ長押しでも削除でき、直後のトーストから復元可能。全シート横断の検索や、シート間のドリルダウンリンクにも対応します。
プロジェクト
左上のプロジェクト名をタップ(または ☰メニュー → プロジェクトの切替・管理)。複数の会社・複数の更改案を切り替えて管理でき、複製・改名・削除も可能です。
自動保存と世代
編集は常時自動保存。さらに日次の世代バックアップが自動で残り(直近10世代)、プロジェクト管理から任意の日の状態に復元できます。
差分着色
☰メニュー →「編集ツール」→ 世代と比較して差分を着色で、過去の世代と比べて 新設/変更/廃止 を自動でステータス付け。変更レビューや作業報告にそのまま使えます。
図の情報
☰メニュー → 図の情報で、図のタイトル・版数・作成者・改訂履歴を管理。印刷/PDFのヘッダーや出力画像の図枠に反映されるので、提出文書としての体裁が整います。
まっさらにする
☰メニュー →「危険な操作」→ 表示中のシートを全消去で、今のシートの内容だけを一括クリア(他シート・他プロジェクトは残ります)。
サンプルで試す
☰メニュー →「危険な操作」→ 表示中のプロジェクトを初期サンプルで上書きでお手本の構成を読み込めます。操作を試したいときに便利ですが上書きされるため、必要な図は先にJSON保存を。

💾データ入出力

図はすべて端末内に保存。バックアップ・共有・他形式への書き出しはここから。

形式方向用途
JSON保存 / 読込完全バックアップ・他端末への移行。図のすべて(全シート・テンプレート・図の情報)を含みます。
PNG / SVG保存・共有表示中シート・範囲指定・全シート連結。図枠と解像度を選べ、凡例(ステータス・回線速度・線種の意味)は自動生成。共有ボタンからLINE/メール直送も。
印刷 / PDF出力A4・A3 / 横・縦、1シート1ページ。ヘッダーにタイトル・版数が入ります。
機器CSV保存 / 取込台帳用の機器一覧。ホスト名/ラベル一致で既存機器を「更新」できるため、CSV保存 → Excelで保守期限やIPを一括修正 → 再取込、という往復が成立します(記入済みセルのみ反映・空欄では消えません)。
配線CSV(対向表)保存 / 取込A機器-Aポート-B機器-Bポートの対向表。取込時は機器をラベル名で照合し、見つからない機器は自動作成 → 自動整列と組み合わせると対向表から図を自動生成できます。
ポート台帳CSV保存1行1ポートで全機器のポートを書き出し(空き/重複も明記)。
drawio保存draw.io(diagrams.net)/ Visio への引き継ぎ用。
共有URL作成 / 受取図をURLそのものに埋め込んで共有。受け取った側はリンクを開くだけで取込を提案されます(サーバーには何も送られません)。
CSVはExcelで文字化けしないBOM付きUTF-8で出力されます。取込用の見出しが分からないときは、各取込画面の空のテンプレートCSVを保存から始めるのが確実です。

✅検証とIP管理

IPの重複や未接続などの不備チェックと、空きIPの把握ができます。

図の検証
☰メニュー → 図の検証で、IP重複・IP/マスク/GWの表記エラー・GWのセグメント外・VLAN不整合・セグメント不一致・ポート二重使用・未接続・保守期限切れ/90日前を一括チェック。結果から該当機器へジャンプできます。同一名の機器を複数シートに描いた場合はIP重複と数えません。
IP管理
☰メニュー → IP管理でセグメントをタップ(またはCIDR入力)すると、使用中IP(ジャンプ可)・GW予約・空きIPの範囲を全シート横断で集計。次に振るIPがすぐ分かります。
CIDR検索
検索欄に 10.0.0.0/22 のようにCIDRを入れると、範囲内のIPを持つ機器を全シート横断で検索できます。
機器一覧
☰メニュー → 機器一覧で全シートの機器を一覧し、IP重複の確認やジャンプができます。

🧪活用レシピ — 機能の組み合わせ例

単機能の説明では見えにくい「現場で効く使い方」を4つ紹介します。

① 全体図 → 拠点詳細図のドリルダウン資料

シート1に全社WAN図を描き、各拠点の機器(または建物アイコン)にリンク先シートで拠点詳細図を設定。閲覧者はタップで掘り下げ、←ボタンで戻れます。同名機器を両方のシートに置けば台帳は1つに名寄せされ、検証・CSVでも二重カウントされません。(導線の図は「機器」章のドリルダウンを参照)

② Excelの対向表から配線図を自動生成

☰メニュー →「配線CSVから接続を一括登録」で空のテンプレートCSVを保存 → Excelで A機器/Aポート/B機器/Bポート を埋めて取込。未登録の機器は自動作成されるので、その後「表示中のシートを自動整列」を実行すれば、表から図が立ち上がります。

③ 更改提案を1枚で — 現行/更改後の出し分け+差分着色

現行図を描いたら更改部分を編集し、撤去機器に「廃止」・追加機器に「新設」のステータスを付与(過去の世代と比べる差分着色なら自動付与)。表示のステータス切替で現行だけ/更改後だけを表示してそれぞれPNG出力すれば、before/afterが同じレイアウトで揃った提案資料になります。

④ フロア図トレースで配線調査メモ

現地でフロア図面を撮影 → 表示 → 下絵(フロア図)で背景に敷き、AP・カメラ・配線をその上に配置。気づきはメモ部品で残し、帰社後に下絵を非表示にすれば図だけをきれいに出力できます。(下絵の図は「表示設定」章の下絵(フロア図)を参照)

📘用語集

本ツールやネットワーク図でよく出る言葉を、ざっくりつかむための早見です。

セグメント
同じネットワーク(IPの範囲)に属する機器のまとまり。表示のセグメント色分けで同一セグメントを同色背景にできます。
アクセス / トランク
スイッチポートのVLANの通し方。1つのVLANだけ通すのがアクセス、複数VLANをまとめて通すのがトランク。線のVLAN設定で指定できます。
二重化(冗長構成)
故障に備えて機器や経路を予備込みで組むこと。STACK / HA / CLUSTER / DR をバッジで表現できます。
対向表
「どの機器のどのポートが、どの機器のどのポートにつながるか」を1行ずつ並べた表。配線CSVとして取込・出力できます。
ドリルダウン
全体図の機器をタップして詳細図へ掘り下げる導線。機器のリンク先シートで設定します。
ホップ(交差)
交差する線を半円でまたいで描き、T字の分岐との誤読を防ぐ描き方。表示の「交差をまたぐ」でON。
下絵
シートの背景に敷く写真・図面。その上をなぞって作図(トレース)できます。
世代バックアップ
1日ごとに自動で残る過去の状態(直近10世代)。プロジェクト管理から任意の日に復元できます。

❓よくある質問

データはどこに保存されますか?クラウドに送られますか?

すべてお使いの端末のブラウザ内(localStorage / IndexedDB)に保存されます。サーバーには一切送信されません。共有URLも、URL文字列そのものにデータを埋め込む方式で、サーバーには何も置かれません。

機器を動かしたいのに線が引かれてしまいます

触れてすぐ動かすと「接続」、少し押さえてから(振動が合図)動かすと「移動」です。判定時間は表示 → 操作の調整で長め(例: 300ms)に変えると移動しやすくなります。フリック配線自体をOFFにもできます。

別の端末に図を移すには?

☰メニュー →「データの保存・取込」→ JSONを保存したファイルを移行先で読み込むのが確実です。小さめの図ならば共有URLを作成してリンクを送る方法もあります。

間違えてシートを消してしまいました

削除直後ならトーストの元に戻すで復元できます。時間が経ってしまった場合は、プロジェクト管理の世代バックアップ(日次・直近10世代)から前日の状態に戻せます。

複数の機器をまとめて動かしたい

2通りあります。恒常的なまとまりなら「作図」カテゴリのグループ枠で囲む(枠ごと動きます)。一時的なら右下複数でなぞって選択し、そのままドラッグです。

印刷すると図が紙からはみ出します

表示 → 用紙ガイドでA4/A3の比率枠を表示し、枠に収まるようレイアウトしてから印刷すると確実です。印刷ダイアログでは用紙サイズと向きを選べます。

現行構成と更改後構成を1つの図で管理できますか?

できます。機器・線に変更ステータス(新設/変更/廃止)を付け、表示のステータス切替で「現行だけ」「更改後だけ」を出し分けられます。出力画像にも反映されるので、提案書の before/after が1枚の図から作れます。

ピンチでブラウザごと拡大したいのにできません

ピンチは既定でキャンバスのズームに割り当てています。視力補助などでブラウザの拡大が必要な場合は、表示 → 操作の調整 → ブラウザのピンチ拡大を許可をONにしてください。

IPv6には対応していますか?

IPv6表記の入力は可能ですが、IP重複チェックやセグメント計算などの検証機能の対象外(素通し)です。
